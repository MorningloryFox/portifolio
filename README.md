# Portfólio — Daniel Alfredo Silva dos Santos

Aplicação estática interativa criada para avaliar a Netlify no plano Free. O conteúdo usa somente informações profissionais fornecidas pelo titular e não contém credenciais, dados corporativos, URLs internas ou integrações externas.

## Teste Netlify

- `netlify.toml` publica a raiz e aponta Functions para `netlify/functions`.
- `/.netlify/functions/portfolio-health` retorna somente metadados sintéticos de validação.
- A versão visual exibida é `v1`; a alteração para `v2` será usada no teste de preview e deploy incremental.
